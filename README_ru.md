# pylowlvl-os

Фреймворк на Python для автоматизации генерации низкоуровневого кода (x86_64) и автоматической сборки загрузочных образов дисков. Проект предоставляет абстракцию над ассемблером `nasm`, позволяя описывать логику инициализации процессора и вывода данных через методы Python.

---

## 🚀 Основные возможности

* **Генерация Real/Protected Mode кода:** Автоматическое формирование директив компилятора (`[bits 16]`, `[org 0x7C00]`), настройка сегментных регистров и указателя стека.
* **Управление видеорежимами:** Переключение стандартных режимов VGA (например, текстовые `40x25`, `80x50`) и VESA графических режимов BIOS через прерывание `int 0x10`.
* **Динамическая генерация процедур:** Функции печати (`aprint`) и задержки (`asleep`) внедряют свои ассемблерные реализации в итоговый листинг только при их фактическом вызове в коде, минимизируя размер бинарника.
* **Гибкий сборщик образов (PLowBuilder):**
  * Компиляция исходного ASM-кода во временных файлах с помощью `nasm`.
  * Генерация плоских бинарных образов (`.bin`, `.img`) для прямой записи через `dd` или запуска в эмуляторе.
  * Создание загрузочных ISO-образов по стандарту ISO9660 с использованием спецификации El Torito в режиме *No Emulation* (без эмуляции флоппи-диска).
  * Автоматический запуск собранного результата в QEMU.

## 🛠 Установка

Для работы с `pylowlvl-os` вам потребуется установленный `nasm` в системе. Установите библиотеку через `pip` прямо из репозитория:

```bash
# Установка последней версии из Git
pip install git+https://github.com/sc0dyx/pylowlvl-os

```

Если вы планируете заниматься разработкой (вносить изменения в код фреймворка), используйте режим редактирования:

```bash
# Клонирование репозитория
git clone https://github.com/sc0dyx/pylowlvl-os
cd pylowlvl-os

# Установка в редактируемом режиме
pip install -e .

```

*Примечание: Перед запуском примеров убедитесь, что `nasm` доступен в вашем `PATH` (команда `nasm -v`).*

## 💻 Пример использования

Ниже приведен рабочий пример инициализации 16-битного окружения, циклического изменения текстовых режимов VGA, вывода строк и последующей компиляции в сырой бинарный образ с автоматическим запуском через QEMU.

```python
from pylowlvl_os.x86_64.pyabstract import PyLowLvl
from pylowlvl_os.builder import PLowBuilder

# Инициализируем генератор кода. 
# Задаем метод вывода строк через стандартный BIOS Teletype (int 0x10, ah=0x0E)
boot = PyLowLvl(aprint16_method="bios_teletype")

# Формируем заголовок 16-битного реального режима ([bits 16], [org 0x7C00], jmp start).
# cli=False оставляет прерывания включенными.
boot.init_enviroment16(cli=False)

# Обнуляем регистры общего назначения (ax, bx, cx, dx, si, di, bp) через xor
boot.clear_all_registers()

# Переключаем видеорежим VGA на текстовый 40x25 (16 цветов)
boot.set_vga_mode("40x25")
boot.aprint_auto("Hello world!")  # Добавляет строку в секцию данных и вызывает печать
boot.asleep_auto(3_000_000)       # Задержка 3 секунды через функции BIOS (int 0x15)

# Переключаем видеорежим на более мелкий текст 80x50
boot.set_vga_mode("80x50")
boot.aprint_auto("Hello world!")
boot.asleep_auto(3_000_000)

boot.aprint_auto("Welcome to pylowlvl_os")
boot.asleep_auto(3_000_000)

# Останавливаем процессор (инструкции hlt и jmp $)
boot.stoooop()

# Заполняем оставшееся пространство нулями до 510 байт и вставляем сигнатуру 0xAA55
boot.finalize_disk_sector()

# Передаем экземпляр сгенерированного кода в сборщик
build = PLowBuilder(boot)

# Запускаем конвейер:
# 1. Сборка кода в один string-листинг.
# 2. Компиляция через nasm в формат raw binary (так как расширение .bin).
# 3. Запуск QEMU с параметрами: -drive format=raw,file=boot.bin,media=disk,index=0
build.run("boot.bin")
```
