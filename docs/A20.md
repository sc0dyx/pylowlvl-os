# Включение линии A20 (`enable_A20`)

Метод для открытия доступа к памяти за пределами первого мегабайта (снятие ограничения адресации IBM PC, где без этого адреса выше `0xFFFFF` циклически заворачивались в ноль). Фреймворк поддерживает три классических способа активации линии A20.

---

## 🛠 Стратегии активации: что выбрать?

### 1. BIOS (`method="bios"`)

Активация штатными средствами прерываний BIOS. Загружает команду `0x2401` в регистр `ax` и дергает системное прерывание `int 0x15`.

* **Плюсы:** Самый безопасный и чистый метод. BIOS сам знает особенности чипсета материнки и делает всё корректно.
* **Минусы:** На старых или специфических эмуляторах может не поддерживаться.
* **Вердикт:** **Основной выбор.** Всегда начинай инициализацию ОС с него.

### 2. Fast A20 (`method="fast"`)

Быстрый способ через системный порт конфигурации чипсета `0x92`. Считывает состояние порта, устанавливает второй бит в единицу (`or al, 2`) и отправляет байт обратно.

* **Плюсы:** Работает мгновенно, код всего в три ассемблерные строчки.
* **Минусы:** На некотором старом железе порт `0x92` может конфликтовать с системой сброса процессора, вызывая спонтанный ребут.
* **Вердикт:** **Запасной вариант.** Юзай, если BIOS вернул ошибку или линия осталась закрытой.

### 3. Контроллер клавиатуры (`method="keyboard"`)

Классический способ через контроллер Intel 8042 (порты `0x64` и `0x60`). Ждет очистки входного буфера (`test al, 2`), отправляет команду записи в выходной порт (`0xD1`), снова ждет и пропихивает команду включения линии A20 (`0xDF`).

* **Плюсы:** Железобетонно работает на древних ПК и музейном хламе из 80-х.
* **Минусы:** Люто медленный. Процессор тупо зависает в цикле ожидания, пока медленный контроллер клавиатуры раздуплится.
* **Вердикт:** **Не нужен**, если только не тестируешь загрузчик на реальном раритетном железе.

---

## 💻 Пример использования

В реальных ОС принято использовать цепочку: сначала просить BIOS, а если не помогло — бить по быстрым портам.

```python
from pylowlvl_os.x86_64.pyabstract import PyLowLvl

boot = PyLowLvl()
boot.init_enviroment16()

# Самый безопасный старт через прерывание
boot.enable_A20(method="bios")

# Если пишется универсальный загрузчик под капризное железо,
# следом можно продублировать быстрым методом
# boot.enable_A20(method="fast")

boot.stoooop()

```
