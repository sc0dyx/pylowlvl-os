# Остановка процессора (stoooop)

Высокоуровневый метод для полной остановки выполнения инструкций процессора и перевода его в бесконечный цикл.

## Как это работает

1. **Сброс флагов:** Снимает флаг прерываний инструкцией `cli`, чтобы процессор не отвлекался на внешние раздражители (вроде клавиатуры или таймера).
2. **Вечный цикл:** Генерирует ассемблерную инструкцию остановки `hlt` внутри бесконечного перехода на саму себя (`jmp $`), намертво замораживая поток выполнения.

## Пример использования

```python
from pylowlvl_os.x86_64.pyabstract import PyLowLvl

boot = PyLowLvl()
boot.init_enviroment16()

# Код, который выполнится
boot.aprint_auto("System halted.")

# Мертвая остановка процессора
boot.stoooop()

```
