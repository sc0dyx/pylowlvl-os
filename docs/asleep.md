# Задержка таймера (asleep)

Метод для приостановки работы процессора на заданное количество микросекунд.

## Как это работает

1. **Прием аргумента:** Метод принимает целое число микросекунд напрямую из Python.
2. **Прерывание:** Переводит это время в два регистра (старшую и младшую часть) и вызывает системное прерывание таймера `int 0x15` (функция `ah = 0x86`).

## Пример использования

```python
from pylowlvl_os.x86_64.pyabstract import PyLowLvl

boot = PyLowLvl()
boot.init_enviroment16()

# Задержка на 3 секунды (3 000 000 микросекунд)
boot.asleep_auto(3_000_000)

boot.stoooop()

```
