# Инициализация окружения (init_enviroment16)

Метод базовой настройки процессора для работы в 16-битном реальном режиме. Он подготавливает сегментные регистры, выставляет указатель стека и генерирует обязательные директивы для компилятора NASM.

## Что делает метод

1. **Директивы компилятора:** Прописывает разрядность `[bits 16]` и адрес загрузки сектора в памяти `[org 0x7C00]`.
2. **Точка входа:** Делает прыжок `jmp start` в обход возможных служебных данных прямо на исполняемый код.
3. **Очистка флагов:** * Если `cli=True` — отключает аппаратные прерывания (`cli`).

* Если `cld=True` — сбрасывает флаг направления строк (`cld`) для корректной работы `lodsb`.

1. **Настройка сегментов:** Обнуляет через регистр `ax` сегментные регистры `ds`, `es`, `ss`.
2. **Инициализация стека:** Выставляет указатель стека `sp` на адрес загрузки (`0x7C00`), чтобы стек рос вниз и не затирал код.
3. **Сброс CS (`flush_cs`):** Выполняет дальний прыжок `jmp 0x0000:.flush_cs` для принудительного выравнивания сегмента кода `cs` в ноль.
4. **Сохранение диска (`save_drive`):** Сохраняет номер загрузочного диска из регистра `dl` в переменную `boot_drive`.

## Пример использования

```python
from pylowlvl_os.x86_64.pyabstract import PyLowLvl

boot = PyLowLvl()

# Полная инициализация с выравниванием CS и сохранением диска
boot.init_enviroment16(cli=True, cld=True, save_drive=True, flush_cs=True)

boot.stoooop()

```
