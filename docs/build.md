# Сборка и запуск образов (`build.md`)

Модуль компиляции `PLowBuilder` отвечает за автоматическую сборку сгенерированного ассемблерного кода в готовые файлы образов, а также предоставляет инструменты для их мгновенного тестирования внутри виртуальной машины QEMU.

Для работы модуля в системе должен быть установлен компилятор **NASM**, а для генерации ISO-образов — Python-библиотека **`pycdlib`**.

---

## 🛠 Поддерживаемые форматы образов

Класс `PLowBuilder` автоматически определяет целевой формат сборки по расширению выходного файла, переданного в параметр `output`.

### 1. Сырой бинарный образ (`.bin` / `.img`)

Низкоуровневый дамп памяти «как есть».

* **Как собирается:** Из массива генерируется временный `.asm` файл, который компилируется через команду `nasm -f bin`.
* **Для чего нужен:** Идеально подходит для заливки напрямую на флешку (через утилиту `dd`) или для быстрого скармливания эмуляторам в качестве жесткого диска или дискеты.

### 2. Образ оптического диска (`.iso`)

Стандартный образ формата ISO9660 с поддержкой спецификации загрузки **El Torito**.

* **Как собирается:** Сначала код компилируется в бинарник, затем с помощью библиотеки `pycdlib` упаковывается в ISO-структуру. Фреймворк использует самый чистый и современный метод **No Emulation** (без эмуляции флоппи-диска) и загружает ровно 1 сектор (512 байт).
* **Для чего нужен:** Необходим для запуска операционной системы через мультизагрузочные утилиты (например, **Ventoy**) или для эмуляции CD-ROM приводов.

---

## 🚀 Основные методы класса `PLowBuilder`

### `build(output: str = "boot.iso") -> None`

Основной метод сборки. Анализирует расширение имени файла и вызывает соответствующий внутренний метод компиляции (`_build_raw` или `_build_iso`). Если формат не поддерживается, выкинет `ValueError`.

### `run(output: str = "boot.iso") -> None`

Компилирует код проекта в выбранный формат, после чего автоматически конфигурирует и запускает виртуальную машину **QEMU** с нужными флагами:

* Если собирается **`.iso`**, эмулятор стартует с флагом `-cdrom`.
* Если собирается **`.bin`/`.img**`, эмулятор подключает файл как основной накопитель с флагами `format=raw,media=disk`.

## 💻 Пример использования

Сборщик принимает экземпляр твоего класса операционной системы (`PyLowLvl`) в качестве аргумента конструктора.

```python
from pylowlvl_os.x86_64.pyabstract import PyLowLvl
from pylowlvl_os.build import PLowBuilder

# 1. Описываем логику ОС
boot = PyLowLvl()
boot.init_enviroment16()

# ... настройка GDT, A20, видеорежима ...

boot.finalize_disk_sector()

# 2. Передаем инстанс ОС в билдер
builder = PLowBuilder(os_instance=boot)

# 3. Собираем и сразу запускаем проект в QEMU
# Для сборки ISO:
builder.run("my_os.iso")

# Или если нужен сырой бинарник:
# builder.run("my_os.bin")

```
