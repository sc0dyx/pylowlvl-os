# Установка видеорежима VGA (`set_vga_mode`)

Метод для переключения видеорежима экрана через понятные человеку текстовые названия. Позволяет выбрать между стандартными текстовыми режимами для вывода букв и графическим режимом для рисования пикселями.

---

## 🛠 Поддерживаемые режимы: что выбрать?

Фреймворк маппит понятные строки в шестнадцатеричные номера режимов BIOS и вызывает прерывание `int 0x10` (функция `ah = 0x00`).

### 1. Стандартный текст (`mode="80x25"`)

Классический текстовый режим (номер `0x03`). Вмещает 80 символов по горизонтали и 25 строк по вертикали. Поддерживает 16 цветов для текста и 8 (или 16) цветов для фона.

* **Вердикт:** **Режим по умолчанию.** Идеально подходит для консольного вывода, вывода логов загрузки и CLI-интерфейсов.

### 2. Крупный текст (`mode="40x25"`)

Текстовый режим с увеличенным размером шрифта (номер `0x01`). Помещает всего 40 символов в строку.

* **Вердикт:** Экзотика. Полезен, если нужно сделать интерфейс крупным и читаемым на старых ЭЛТ-мониторах.

### 3. Мелкий текст (`mode="80x50"`)

Попытка выставить режим повышенной плотности текста. На реальном железе требует дополнительных махинаций с регистрами VGA-контроллера и подгрузки мелкого шрифта `8x8`.

* **Вердикт:** В текущей версии работает как **фоллбэк (откат) на стандартный режим `0x03**` (`80x25`).

### 4. Графика (`mode="320x200"`)

Легендарный графический режим (номер `0x13`). Превращает экран в матрицу из $320 \times 200$ пикселей, где каждый пиксель может быть одного из 256 цветов палитры.

* **Вердикт:** **Выбор для создания графики.** Именно в этом режиме пишется маппинг пикселей напрямую в видеобуфер по адресу `0xA0000` (для рисования простейших GUI, картинок или игр).

---

## 📋 Сводная таблица режимов

| Строка параметра | Тип режима | Разрешение | Количество цветов | Номер для BIOS |
| --- | --- | --- | --- | --- |
| **`"80x25"`** | Текст | 80 × 25 (символов) | 16 | `0x0003` |
| **`"40x25"`** | Текст | 40 × 25 (символов) | 16 | `0x0001` |
| **`"80x50"`** | Текст | Сброс на 80 × 25 | 16 | `0x0003` |
| **`"320x200"`** | Графика | 320 × 200 (пикселей) | 256 | `0x0013` |

---

## 💻 Пример использования

Метод завязан на прерывания BIOS, поэтому его можно вызывать **только в 16-битном реальном режиме** (до прыжка в Protected Mode).

```python
# Включаем стандартную консоль 80 на 25 символов
boot.set_vga_mode(mode="80x25")

# Или врубаем графику, если хотим рисовать пикселями
# boot.set_vga_mode(mode="320x200")

```
